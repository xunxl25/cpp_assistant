# 任务：从 GESP 考试题目 PDF 文件中提取选择题和判断题，生成结构化 JSON

## 输入信息
- 文件类型：PDF（GESP 考试真题）
- 目标内容：选择题（single_choice）和判断题（true_false）

## 执行步骤

### 1. 内容定位
- 扫描 PDF，定位包含"2 判断题（每题 2 分，共 20 分）"的章节。
- 从该章节开始，提取所有判断题题目和答案。
- 向前追溯，定位"1 单选题（每题 2 分，共 30 分）"章节，提取所有选择题。

### 2. 答案生成（重要变更）
- 不依赖 PDF 中的答案标记。由于 PDF 解析可能导致答案符号（√、×、A/B/C/D）无法被正确识别或缺失，所有答案一律由 LLM 根据题目内容和代码逻辑自行作答生成。
- 判断题答案：LLM 分析题干正确性后，直接输出 T 或 F，不做符号映射。
- 选择题答案：LLM 分析选项后，直接输出 A / B / C / D。
- 生成答案时需确保推理正确，并在 explanation 中给出完整的解题依据。

### 3. 代码识别与格式化
- 识别题目中的 C++ 代码片段，恢复标准格式：添加换行、缩进，确保可编译（如 int main() { ... }）。
- 代码缺失/损坏处理（重要变更）：
  - 若题干中的代码片段为图片形式、无法从 PDF 中提取为文本，或提取出的内容明显残缺、乱码、逻辑不完整，则在题干末尾追加提示文字："（参照原PDF代码）"
  - 此时 LLM 应根据题干描述、选项和上下文推断题意作答；若无法确定，explanation 中需注明"代码内容缺失，答案基于题干描述推断"。

### 4. 生成 JSON 结构
- 每个题目生成一个字典，包含以下字段：
  - id：根据题号生成（如 gesp-4-202403-sc-1 或 gesp-4-202403-tf-1）
  - exam：固定为 {"type": "GESP", "level": 4, "date": "yyyymm"}（从文件名提取日期）
  - knowledge_points：从指定列表匹配（如"指针类型的概念及基本应用"）
  - type：single_choice 或 true_false
  - question：题目文本（不含选项；代码缺失时末尾追加"（参照原PDF代码）"）
  - options：仅选择题需要（判断题无此字段）
  - answer：LLM 生成的答案（T/F 或 A/B/C/D）
  - explanation：LLM 根据解题逻辑生成（代码缺失时需注明）

### 5. 输出格式
- 返回一个 JSON 数组 List[Dict]。
- 文件命名：type-level-date.json（如 gesp-4-202403.json）。

## 注意事项
- 内容定位优先：通过章节标题（如"2 判断题"）定位，而非固定页码。
- 答案由 LLM 自行生成：忽略 PDF 中的答案标记（可能识别错误或缺失），以 LLM 的推理结果为准；判断题直接输出 T/F，无需符号映射。
- 代码格式化：确保 C++ 代码可编译（如保留 main() 结构）。
- 代码缺失标记：代码无法提取或内容异常时，题干末尾必须追加"（参照原PDF代码）"，且解释中说明答案为推断结果。
- 知识点匹配：从指定列表中选择，若不匹配则留空。
